# 明日方舟干员抽取器

独立维护的纯静态项目，计划部署于 `https://yubo.run/arknights/picker/`。
与 yubo.run/user 一样使用 CDN 全局脚本方式加载 Vue 3 和 Element Plus，无需 Node.js 或构建步骤。

## 使用

通过 HTTP 服务打开 `index.html`。页面需要联网加载 Vue、Element Plus 和干员数据。
默认数据源为 `https://yubo.run/arknights/arknights-dictionary/operator.json`，在 `app.js` 的 `DATA_URL` 中配置。
其他域名或本地预览需要数据源允许跨域 GET；生产部署在 yubo.run 下时使用同源请求。

输入字符串种子，设置星级、职业及手动选择范围，再指定人数抽取。同一轮按干员 ID 全局不放回。
改变范围不清空历史；重新开始清空历史并解锁种子。撤销最后一批会放回该批干员并恢复抽取序号。
仅抽所选模式下未选择任何干员时，候选为空；人数不足会提示，不产生部分结果。

## 文件与扩展

- `index.html`：页面结构和 Vue 模板。
- `style.css`：响应式布局。
- `picker.js`：筛选定义、字符串哈希和确定性抽取。
- `app.js`：数据加载、交互和本地状态。
- `themes.js`：主题注册、加载与偏好保存。

## 像素样式与主题

默认使用与个人中心相同的 Fusion Pixel 字体和 `wei-matrix.css`，从 `https://yubo.run/assets/css/` 加载唯一源文件，不在本仓库复制。
加载顺序为 Element Plus 基础样式、暗色变量、字体、页面布局、主题覆盖。
`style.css` 保留像素字体、直角控件和响应式布局，颜色引用 Element Plus 变量，不固定在 Matrix 配色上。
共享 Matrix 样式负责暗色配色、扫描线和减弱动态效果偏好；弹出菜单和确认框同样继承像素字体与主题。

新增主题时，在 `themes.js` 的 `themes` 注册表中添加 `name`、`label`、`dark` 和 `href`。
本项目专属主题可放入 `themes/`；共享主题继续引用其规范地址。覆盖 Element Plus 变量即可同步更新页面和组件，可附加页面选择器覆盖。
主题样式在布局之后加载，因此也能覆盖字体或几何样式。直播页主题具有不同的变量和 DOM 契约，不能保证直接兼容。
注册多个主题后，页首自动显示主题选择器，无需改动抽取逻辑。

支持 `?page_style=wei-matrix`，优先级为 URL 参数、独立的本地主题偏好、默认主题。
URL 仅接受已注册名称，不接收任意 CSS URL。未知名称提示并保留默认主题。
切换主题先下载新样式，成功后替换旧样式；失败或超时保留当前主题并提示。
界面切换会保存至 `arknights-operator-picker-theme`，URL 指定的主题仅影响当次打开。
主题偏好与抽取记录独立，不影响候选、种子或历史。初次离线时共享样式和字体无法加载，只有 Element Plus 本身也可用时才有基础样式。

在 `Picker.filterDefinitions` 中声明新筛选项的 `key`、`label`，可选 `getValue(operator)`。
目前支持标量或数组的精确匹配；数组字段任一值匹配即可。缺失字段不匹配已选条件，未启用的筛选不限制候选。
控件选项从数据提取，不会自动暴露未声明的新字段。复杂范围、布尔值或日期控件应新增明确的适配规则。

## 种子与记录

`picker-v1` 使用 FNV-1a 将字符串、抽取序号及排序后的候选 ID 转换为 32 位种子，再使用 Mulberry32 逐次抽取并移除候选。
采用 kaiju 的字符串转种子思路，不与其 MD5 或按日变化规则保持结果兼容；不用于安全用途。
相同算法、种子、候选与序号会产生相同结果，每位剩余候选等概率，不按星级加权。

本地存储键为 `arknights-operator-picker-v1`。记录包含历史名字、候选 ID、筛选条件、抽取序号和数据摘要。
数据变化时提醒，历史按 ID 保留，后续使用新数据；历史名字不会随数据改名。
时间以 ISO 字符串保存，界面按北京时间展示。无服务器写入、账号系统或跨设备同步。
浏览器禁止存储或容量不足时会提示；清除浏览器数据会丢失进度。

## 验收

检查桌面和手机布局、数据加载失败重试、筛选交集、仅抽所选空集、人数不足、连续不重复、刷新恢复、撤销、重新开始及取消确认。
验证固定种子与候选得到一致结果，数据顺序变化不影响结果。数据更新提示与存储不可用也需覆盖。
仓库没有包管理器或统一构建入口。依赖 CDN 或数据源失败时不能视为完成浏览器运行验证。
